# C# Learning

A hands-on repository for learning **C# and .NET** through exercises, experiments, and small projects.

## Goals

* Build a solid foundation in C# and .NET
* Learn through practical implementation
* Explore language features and core concepts
* Improve problem-solving and software development skills

## Topics

* C# Fundamentals
* Object-Oriented Programming
* Collections & LINQ
* Exception Handling
* Generics
* Delegates & Events
* Async/Await
* .NET Fundamentals
* Small Practical Projects
